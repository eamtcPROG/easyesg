UX-40 · UC-32

The unit is theirs

The unit list is written from invoices, not from a standard's annex. Moldovan gas bills read in cubic metres; some read in gigacalories; a fleet card reads in litres. All three are first-class, and none of them asks the user to do arithmetic before typing.

The unit is remembered, not re-asked

Next year's report starts with the same sources, sites and units, values cleared. A returning user confirms rather than rebuilds.

Decimal comma, thousands space

Input accepts 1 700, 1700 and 1.700 and displays the locale form. A figure typed off an invoice is never rejected for punctuation.

Twelve monthly bills, one line

A source can be entered as one annual figure or expanded into months. The expanded form totals for you and flags a missing month rather than quietly summing eleven.

A unit no list has

Where the invoice unit is genuinely absent, the field can hold the raw text and be declared unavailable with a reason. It never becomes a guessed number.

Arithmetic in words, not notation

Each step names what was done before showing the number. A user who does not read the middle two lines still learns that two conversions happened and where they came from.

The same four steps in the export

The methodology annex prints this table per source. Preview shows it identically, per UX-45 — the reader of the PDF sees what the author saw.

Rounding is disclosed, not hidden

Totals are summed unrounded and rounded once, at the end. Where that makes the parts appear not to add up, the summary panel says so in a line rather than letting the user find it.

Expanded is an address

An open derivation is in the URL, so a question about one line is answered with a link, not with instructions on where to click.

UX-43 · UC-34

Replacing a computed figure

Overriding is legitimate — a metered figure from the landlord beats a modelled one. What is not legitimate is a substituted number nobody can distinguish from a computed one, so the reason is required at the point of substitution and travels with the figure into the export.

The marker is the same one used for every substituted figure in the product, so a reader learns it once.

Reverting is one action

The computed value is never discarded, so returning to it is a single press and does not require re-entering anything. Field history keeps both, attributed (UX-68).

No reason, no substitution

The confirming action stays unavailable until the reason has content. This is the one place in the wizard where a field blocks an action, and it blocks only that action.

Not an error state

A substituted figure is override in the eight-state vocabulary — amber, resolved, listed in the validation panel as a decision recorded, never as a problem outstanding.

A wildly different figure still asks

An override more than an order of magnitude from the computed value adds an inconsistency in the panel. It is permitted, and it is noticed.
