00 — Direction

The four decisions everything else follows from

Character
Confident and modern

Crisp edges, higher contrast, generous whitespace. This reads as a commercial product an SME chose, not a form the state issued.

Accent — exactly one
Pine #2E6A4F

Primary action and active state only. Never used for a validation state, so an accent button is never mistaken for a success marker.

Neutrals
Cool grey, low chroma

A blue-leaning grey ramp carries roughly 90% of every screen. Chroma stays under 0.02 so figures and state colour never fight the page.

Type
Onest, one family

Onest across every text role, with IBM Plex Mono for identifiers and code. It carries comma-below diacritics and full Cyrillic (UX-84).

MUD

Familiar-but-distinct. Structural conventions are borrowed from the Unified Design Model — one accent, role-named colour, a fixed spacing scale, state carried by icon and label as well as hue. No MUD value, asset or component enters the product until AGE clears commercial licensing (UX-131). Everything below is platform-authored.
01 — Architecture

Three tiers, and no component reaches past tier 3

Tier 1 is the only place a literal exists. Tier 2 names intent. Tier 3 names the place it is used. Swapping the identity — including to a MUD-approximating theme — means editing tier 1 and, where a component maps differently, tier 3.

06 — Space, shape, elevation

One scale, two densities, three elevations

Spacing derives from a single 4px-based scale; arbitrary values are prohibited. Comfortable is the tenant default and compact belongs to the admin queues — same tokens, different step choices.

Elevation means transience, not importance. Flat for content, raised for a popover or sticky bar, overlay for dialogues and the re-authentication surface. A card does not float.

Rules that hold regardless of theme
UX-88Nothing essential is conveyed by animation alone, and every motion honours prefers-reduced-motion by dropping to an instant state change.
UX-87One coherent icon set at 20px and 24px on a 24px box. Every icon has an accessible name; none is the sole carrier of state or action.
UX-106Interactive targets are never below 24×24, which binds the inline field actions — not available, carry forward, finding links — where the temptation to shrink is greatest.
UX-115No loading affordance below 300ms. Skeletons match the final layout; spinners are for indeterminate waits with no known shape.
